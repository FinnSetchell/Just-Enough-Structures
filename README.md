# Just Enough Structures

**A structure browser in the style of JEI.** Press **K** to see every structure in your game. Turn it around in 3D, see each layer and open its chests to see what they can hold.

It's in alpha. Builds are on the [Releases](https://github.com/FinnSetchell/Just-Enough-Structures/releases) page.

## How it works

Each structure is generated by its own mod's code, the same way it generates in a world. Nothing is read from structure files.

- The server generates the structure along the same path as `/place structure` and world generation
- Jigsaw layouts, processors, and blocks or loot placed by code come out as they do in a world
- It's generated into chunks that belong to no world, so nothing in your world is placed, loaded or changed
- What was placed is sent to your game to draw: blocks, containers, mobs and spawners
- Opening a chest rolls its loot table on the server with the game's own loot code, so loot added by other mods is included
- Item chances come from thousands of rolls of each table
- The mod has to be on the server and the client

Two things are saved in `.cache/justenoughstructures`, so they are only worked out once:

- Each structure's first preview
- The loot scan that item search and the Found in structures pages use

Both are redone when your mods or datapacks change. The first loot scan runs in the background. It takes a few minutes with a lot of structure mods, and longer in the biggest modpacks. The folder is safe to delete.

## Opening a structure with a command

`/jes open <structure>` opens the browser on that structure. `/jes open` on its own opens the browser.

```
/jes open minecraft:ancient_city
```

Anyone can run it, and it opens for the player who ran it. A quest, guide book or chat link can use it to send players to a structure, which helps when setting up FTB Quests.

## Other mods

- JEI, EMI or REI: an item's recipes get a Found in structures page
- Explorer's Compass: its structure list gets a Preview button, and while you hold the compass the browser gets a button that opens it on the structure you're looking at
- FTB Quests: clicking a Find Structure task opens its structure in the browser
- Mod Menu with Cloth Config: a settings screen for the browser and for the worlds you host

### Built to survive updates

Pack tools never changes a mod's files. Your changes are saved in your config folder, so they ship with your modpack.

* **A mod updates a loot table you edited:** merge the update in with one click, keeping all your changes
* **A mod changes a structure:** your chest and spawner changes still apply, and are skipped if that chest or spawner is gone
* **A mod or datapack is removed:** your changes for it are kept, ready if it comes back
* **A mod or datapack is added:** its structures show up automatically
* **A mod has a broken block or mob:** it's left out of the preview instead of crashing the game
* **You make a mistake:** edits the game can't load are never saved, and a file broken by hand is ignored until it's fixed
* **Nothing is lost:** removed changes are backed up, and a crash can't corrupt your files

Good to know:

- Everything is in `config/justenoughstructures` and applies from the next `/reload`
- A chest or spawner change applies everywhere its template is used, which can be more than one structure
- Chests placed by a structure's code, like the desert pyramid's, can't be changed one at a time. Edit their loot table instead

### Server settings

`config/justenoughstructures/server.json5` is written the first time a world or server starts. Pack tools can change it in game.

- `pack_tools`: who can use Pack tools. On a server nobody can until they are named here, given a permission level, or given `justenoughstructures.pack_tools` by a permissions mod
- `locate_permission` and `teleport_permission`: who can locate and teleport to structures from the browser. Operators by default, like `/locate` and `/tp`
- `hidden`: structures or whole mods to leave out of the browser
- `show_loot_locations`: set to `false` to hide where loot is. The Loot tab still lists what it can be
- `container_changes`: set to `false` to switch off every chest and spawner change without losing them

## For mod authors

A structure can have a file at `data/<namespace>/justenoughstructures/structures/<path>.json`, in a mod's jar or a datapack. Every field is optional.

```json
{
  "notes": "Shown in an Author's notes section on the Info tab.",
  "author": "Moog",
  "hide_loot_locations": true
}
```

- `notes` is a string or any text component, so it can be translated and styled. Use `\n` for a new line
- `author` changes the section's title to "Notes from Moog"
- `hide_loot_locations` hides where this structure's loot is

Structure names come from the translation key `structure.<namespace>.<path>`, the same one Explorer's Compass uses.
